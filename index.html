Log 20 — Sistema de Gestão Logística

Sistema web voltado à gestão e ao monitoramento de operações logísticas, desenvolvido para centralizar informações, automatizar processos e acompanhar indicadores de desempenho operacional.

Saiba mais...

O Log 20 surgiu da necessidade de solucionar problemas reais relacionados ao monitoramento de entregas, gestão de equipes e análise de dados logísticos.

O sistema transforma arquivos operacionais em informações estruturadas, permitindo consultas históricas e acompanhamento de indicadores para apoiar a tomada de decisões.

Funcionalidades implementadas:

• Autenticação de usuários com JWT e bcrypt.
• Cadastro e gerenciamento de motoristas.
• Importação e processamento de arquivos CSV.
• Modelagem e persistência de dados relacionais.
• Indicadores de desempenho operacional.
• Monitoramento de perdas de jornada.
• Ranking de perdas de jornada por motorista.
• Consultas e filtros por período.
• Integração entre frontend e backend.

Arquitetura:

Aplicação modular utilizando Flask Blueprints, com separação de responsabilidades entre rotas, services, models e templates.

Tecnologias:

Python Flask Blueprints MySQL SQLAlchemy Flask-SQLAlchemy APIs REST HTTP JSON JWT bcrypt HTML5 CSS3 Jinja2 JavaScript Fetch API Git GitHub Postman

Status: Projeto em desenvolvimento contínuo, com evolução das funcionalidades conforme os requisitos operacionais.
